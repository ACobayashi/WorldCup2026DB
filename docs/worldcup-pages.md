# 世界杯网页功能

本文件记录实际实现，正式课程材料仍放 `data/team/`。开发分支为 `feature/worldcup-data-import`，使用现有 18 张表，不新增表。页面继续沿用 FOURWARD 深色风格，绿色表示积极结果/晋级，蓝紫色维持公共导航。

## 比赛详情

入口 `/worldcup/?view=matches&id=内部比赛ID`，从赛程卡片进入。顶部显示国旗、双方、比分、阶段、北京时间和场馆；常规、加时和点球分别展示。下方是双列首发/替补名单，以及技术统计与事件列表。缺失数据显示 —，不推算出场分钟或助攻。允许替补席球员领牌，乌龙球有独立标记。控球率保留来源值，不把争夺中比例强行分给任一球队。

模型 `MatchDetail` 读取名单、统计与事件；`MatchController` 在验证比赛存在后组装详情；视图负责转义及排版。`action=match` 增加 lineups/statistics/events 字段，原有比分和支持字段兼容。

国旗为本地 SVG，来自 lipis/flag-icons（MIT），署名见 `public/assets/images/flags/CREDITS.md` 和 LICENSE。按固定 FIFA 代码白名单选取，不直接使用数据库图片 URL。

验证命令：`php scripts/check-worldcup-pages.php`、`php scripts/check-worldcup.php`、`node scripts/check-prototype.mjs`。新增页面验收使用本机已导入的完整快照，不写入数据库。

当前浏览器自动视觉检查被工具中止：该 Windows 浏览器不支持 URL 策略检查。已停止该检查路径；接口与服务器渲染输出均进行验收，不将其表述为已完成浏览器视觉验收。

## 国家队页面

入口 `/worldcup/?view=teams`，支持中英文及代码搜索。球队卡片、详情页均使用本地国旗。详情展示本届分组、完整 26 人名单和该队比赛记录；名单按门将/后卫/中场/前锋分组，只有号码、姓名、位置及由逐场记录汇总的出场、进球、射门。单场缺失统计不补零，不展示生日和身体资料。详情名单不分页，避免默认 20 条漏掉最后六人；独立 `players` API 仍保留原分页合约。

球队进球包含有利于本队的乌龙球，球员进球不含乌龙球；双方数据均不计点球大战。球队赛程以本队比分在前展示，并标注主/客队。`TeamController` 在模型查询后组装完整名单、赛程和摘要，`Team` 模型负责聚合 SQL。验收逐队核对 48 队均展示 26 人及至少三场比赛。

## 积分榜与淘汰赛图

入口 `/worldcup/?view=groups`；子分类为 `panel=standings|thirds|bracket`。通过普通链接切换，不依赖前端脚本。小组榜在宽屏双列、窄屏单列，提供国旗、赛/胜/平/负、进失球、净胜球、积分，绿色表示已晋级。球队和比赛均可跳转详情。

排名由本地已结束的小组赛赛果实时计算，不持久化积分或新增数据表。遵循 [FIFA 2026 规程](https://digitalhub.fifa.com/m/636f5c9c6f29771f/original/FWC2026_regulations_EN.pdf) 第 12–13 条（2026 年 5 月版本，正文第 23–27 页）：同分先算相互战绩，仍同分的子集重新比较，再看总净胜球和总进球。未导入完整球员/官员公平竞赛分或历史 FIFA 排名，无法继续区分时保留并列，绝不用球队代码冒充体育排序。小组尚未全部结束时显示暂定排名，不提前标记最终晋级。

各组前二及八个最佳第三名共 32 队晋级，已核对与实际 32 强参赛者完全相同。第三名横向比较不看相互战绩；当前厄瓜多尔和加纳的积分/净胜球/进球相同，保留并列第 3–4 名，两队都已在前八范围内。如果并列跨越第八名边界，标为待确认，不虚构第八支晋级队。

`Standings` 模型提供纯函数排名及数据库汇总，`StandingsController` 提供只读 `action=standings` 和 `action=bracket`。原 `groups` 接口保持分组名单和分页合约。`data/worldcup/standings-reference.json` 是早期懂球帝 26123 赛季快照的最小字段提取，仅供独立验收；来源链接、原响应 SHA 和时间未知说明保留，运行时不请求外站。48 队的名次及七项数值均与该参考一致。

淘汰赛按本届实际比赛编号的胜者关系排列，而非开球时间或列表下标。`knockout-paths.json` 从 FIFA 响应的 W73 等名额字段提取，并按上述规程第 12 条核对，保留源响应哈希。图中有 31 场争冠对阵、30 条连接线，三四名决赛单列；每个节点从本地数据库读取球队、比分和实际胜者。数据关系冲突时给出提示并隐藏连线。较窄屏幕使用可键盘聚焦的横向滚动区域。

`php scripts/check-worldcup-standings.php`：491 项规则边界、48 队独立排名/统计核对和晋级关系检查。`php scripts/check-worldcup-pages.php`：327 项比赛、48 队和积分/淘汰赛页面输出检查。均不保留测试数据。原 42 项世界杯、30 项留言、28 项全量导入验收继续通过。
