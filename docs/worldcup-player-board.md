# 球员面板与统计榜

实际功能记录，由韩羽宸维护。复用既有 18 张表，新增一个可空 JSON 文本列 `wc_player_match_stats.advanced_stats`，不新增数据表。

## 数据准备

在已有完整核心数据的机器执行：

```powershell
python scripts/worldcup_player_metrics.py
python scripts/worldcup_goalkeeper_metrics.py
php scripts/import-player-metrics.php
php scripts/check-worldcup-players.php
python -m unittest discover -s tests -p test_worldcup_player_metrics.py
```

新机器先按 `data/worldcup/README.md` 初始化并导入 `full/complete.json`。完整初始化 SQL 已包含新列；现有库由扩展导入脚本检查列存在性后执行 `003-player-advanced-stats.sql`。DDL 在事务外执行且不清空表，3288 行更新在事务中完成，失败回滚；相同内容哈希跳过。可传数据文件路径及 `--dry-run` 做事务回滚验证。成功批次写入既有 `wc_import_batches`。

扩展数据来自 Hesham El Alamy 的 [Worldcup26](https://github.com/Alamyy/Worldcup26)，沿用 CC BY 4.0 署名，具体 CSV 为 `player_in_possession_distributions.csv` 与 `player_out_of_possession.csv`。选取 17 项逐场进攻/防守指标，如传中、破线、推进、拦截、解围、封堵、夺回球权、对抗和抢断。源快照、URL、原响应及选取后哈希保存在 `data/worldcup/player-metrics/`。精确采集时间未记录，保留 null，缓存写入时间单列。原始姓名、比赛、球队、球员、号码和出场记录逐字段核对；第 47 场及截断姓名沿用已验证的定向映射，不建立新的模糊匹配。

`tackles_made_won` 按源文件的“尝试 / 成功”格式拆开，成功不得超过尝试。扩展值只能是非负整数或 null；缺失不补零。门将数据另从懂球帝104场官方阵容响应的逐人“门将”统计组采集，共214条实际出场记录，严格使用 FIFA 球员/比赛编号映射。记录扑救、阻止进球、禁区内扑救、出击/成功、摘高球、拳击球、扑出点球和点球大战扑救；缺项保留 null，不从球队射正和比分反推。

## 页面

- 国家队球员卡片、比赛阵容姓名可点击进入 `?view=player&id=内部球员ID`。
- 所有列表、阵容、榜单和对比页使用懂球帝中文名；仅球员详情页在中文主名下保留英文名对照。顶部保留号码、位置和国家队国旗，并接入已核对身份的懂球帝球员头像。
- 赛事总览：出场、首发、进球、助攻、射门、成功传球、加权传球成功率；综合能力六维图及分组方格统计。
- 单场发挥：使用 `match_id` 选择该国家队的比赛，按进攻、传球、防守与对抗分组；门将额外显示专用“门将”分组。支持首发、替补、未上场和名单未记录状态，个人领牌等事件单列。选中比赛必须属于该球队赛程。
- 逐场记录、球员事件均可回到比赛详情；未上场不生成技术表现，替补席领牌仍保留。

## 综合能力六维图

速度、射门、传球、盘带、防守、力量以及综合评分逐人读取懂球帝球员页，固定使用 0–100 量程。它与本届赛事统计分开展示，不把推进、过人、进球等比赛数据换算为能力值。快照位于 `data/worldcup/player-abilities.json`，运行 `python scripts/worldcup_abilities.py --all --workers 12` 可复现。当前已逐一检查 1,248 人：1,056 人有完整六维值，192 人的官方能力接口返回暂无数据；后者保持“暂无”，不插值、不编造。

对比图使用蓝色和橙色区分两名球员。悬停或点击雷达图的能力项可查看双方评分与分差，点击图例切换显示的球员。实际表现柱状图默认展示全部可用指标，每行按该指标单独缩放并标出原始值。点击指标名或柱形，或在下拉菜单中选择指标，可切换到共用原始刻度的单项图。原始数据表可展开。球员选择器支持中文名、国家队和位置搜索。球员详情中的逐场柱状图与比赛选择框同步，点柱形后更新该场明细和页面链接。

## 中文姓名

页面优先显示可核验的完整中文名：先用英文 Wikipedia 条目与 Wikidata 中文标签/中文条目做精确身份连接，再以 FIFA 官方 `zh-CN` 本届阵容的相同球员 ID 补充；两者均未覆盖时继续使用已核对的懂球帝中文简称，不自动音译。英文名仍只在个人详情页作为对照。生成顺序为 `worldcup_full_names.py`、`worldcup_fifa_zh_names.py`，必要时再运行 `worldcup_wikidata_search_names.py` 对剩余项执行严格同名足球员搜索。

## 热区核查

已检查懂球帝本届全部 104 场比赛的官方阵容响应，共 5,322 个球员比赛条目，所有条目的 `has_heatmaps` 均为 0。懂球帝提供了传球、推进、跑动等详细计数，但未向这些世界杯比赛返回活动坐标。球员页原空热区模块已移除；阵型站位、射门位置或随机点不会冒充热区。核查结果记录在 `data/worldcup/player-heatmaps.json`，未来只有取得真实单场坐标后才会在比赛详情中启用。

## 旧位置统计雷达口径

计数使用场均值，不冒充每 90 分钟。每个指标须覆盖球员所有出场场次才能进入雷达；缺失指标不画点，完整指标不足三项或尚未出场时隐藏雷达。比较对象是本届同位置已上场且该项记录完整的球员。按单项最高值归一化至 0–100，同时画同位置均值虚线；它不是百分位或能力评分。某项全为零时归一值为零，不除零。原始场均数和百分比在图下表格显示。

| 位置 | 维度 |
| --- | --- |
| 门将 | 扑救、阻止进球、禁区内扑救、成功出击、摘高球、传球成功率 |
| 后卫 | 拦截、成功抢断、解围、封堵、夺回球权、赢得空中对抗 |
| 中场 | 成功传球、传球成功率、完成破线、推进、成功传中、过人次数 |
| 前锋 | 进球、射门、过人次数、推进、成功传中、成功传球 |

未引入缺少可靠逐人来源的扑救率、单场助攻拆分、分钟、xG、xA、射正和跑动数据。赛事助攻总计取自懂球帝 `26123` 赛季完整非零助攻榜，未出现在非零榜中的已映射名单球员记为 0；不把总计拆分到单场。传球成功率按成功总数/尝试总数加权计算，尝试为零或覆盖不完整时为空。

## 球员榜

入口 `?view=leaders`，API `action=player_rankings`；按 `metric` 切换统计项，`position` 筛选，沿用分页。已增加扑救榜，仅纳入懂球帝逐场扑救覆盖完整的门将。其他计数榜同样只纳入已出场且该项覆盖完整的球员，同数值并列，不额外按出场数或姓名硬分体育名次。助攻榜使用赛事总计；红黄牌榜单独聚合已记录事件，允许未上场替补领牌，不当作完整公平竞赛分。

模型 `PlayerBoard`、控制器 `PlayerController`、球员及榜单视图分别承担 M/V/C 职责。个人 API `action=player&id=...&match_id=...` 返回赛事汇总、位置雷达、球队全部赛程、选中单场及已记录事件。所有输入按白名单验证，名称转义，图形由数值生成 SVG，无额外前端依赖。

## 验收

`check-worldcup-players.php` 验证四类位置、未上场球员、赛事与球队汇总一致性、全部可用榜单、并列、位置过滤、单场切换、错误输入及缺失值/零分母边界。扩展清洗有 7 项 Python 检查，覆盖身份变动、重复、缺行、异常计数和空值。原有页面、世界杯、积分榜及导入检查保持通过。

桌面排版与实际数据已完成浏览器检查。门将个人页和扑救榜预览分别位于 `docs/screenshots/goalkeeper-profile.png`、`goalkeeper-saves-leaderboard.png`；赛程组合筛选与比赛阵容门将数据预览位于 `match-search-filter.png`、`match-goalkeeper-data.png`。
