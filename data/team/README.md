# 团队作业

正式团队材料放在本目录，文件名按老师的最终要求填写。

1. 需求文档
2. 设计文档
3. 实现文档
4. 用户手册
5. 部署文档
6. 项目展示
7. 录屏讲解

管理员从“个人中心 → 上传与发布作业”选择“团队作业”提交，保存草稿后点击发布。运行时文件放在 `uploads/`，不进入 Git；正式提交仓库时须将最终材料另外整理在本目录，不用外部链接代替要求提交的文件。

## 已整理材料

需求、设计、实现、用户手册四份 PDF 已放在本目录，文件名包含四位成员学号。设计文档的可编辑 LaTeX 源码位于 `design-document/`，`design-document-source.zip` 为对应源码压缩包；源码目录中的编译 PDF 和辅助文件不重复提交。

## 阅读更正

需求文档“注册、登录与个人中心”中的“密码为 12–72 字节”是旧版网页注册规则。当前普通用户网页注册密码只需非空、不超过 72 字节、不含空字符，且两次输入一致，不再要求至少 12 字节。CLI 创建成员或管理员账号仍要求 12–72 字节。PDF 原件保留，其余功能说明应结合仓库当前实现核对。
